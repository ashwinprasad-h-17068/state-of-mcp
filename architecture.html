WHY REMOTE?

Lower setup friction

Remote MCP is attractive to end users because installation is easier and authentication can happen through the browser session, without manually creating credentials such as client IDs and refresh tokens.

WHY LOCAL?

More control

Local distributions are maintained by the Zoho Analytics team and contain custom logic over regular APIs. They support different development environments and preferences.

SPECIAL PACKAGING

Claude Marketplace and Plugins

Claude Marketplace

The Analytics MCP is also listed on the Claude Marketplace. Claude requires the mcp servers to be bundled in a MCPB package format. The Analytics MCPB is built over the Node.js local version.

Plugins

Plugins use a tagged Node.js-based MCP package plus an Agent skill. Because prompt bloating is not a concern in this setup, the Plugins version can expose a larger set of tools.

!
Important nuance

“Remote” does not automatically mean “same functionality.” The Self-Hosted Remote server is based on the Python Docker code, and file-transfer tools such as import/export are not available there due to technical constraints.
